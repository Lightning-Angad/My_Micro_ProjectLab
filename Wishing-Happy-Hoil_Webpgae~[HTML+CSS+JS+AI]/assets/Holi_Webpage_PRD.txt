PRODUCT REQUIREMENTS DOCUMENT (PRD)

Project Title: Colorful Holi Celebration Responsive Webpage

1.  Product Overview

Purpose: Develop a colorful, responsive, single‑page Holi celebration
webpage using HTML, CSS, and JavaScript. The page must replicate the
reference design exactly and include synchronized lyrics, music, and
animation effects.

Goals: • Exact visual match with reference • Fully responsive (PC and
Mobile) • Automatic looping background music • Spotify‑style
synchronized lyrics • Interactive color shower animation • Proper folder
organization

------------------------------------------------------------------------

2.  Features and Requirements

Feature 1: Background

• Fullscreen background image from assets/images/bg.jpg • Cover entire
viewport • Black gradient overlay after image for readability

------------------------------------------------------------------------

Feature 2: Main Greeting Text

Text: HAPPY HOLI

Requirements: • Center aligned • Gradient of 5 colors • Responsive font
size

------------------------------------------------------------------------

Feature 3: Synchronized Lyrics Glass Box

nawaabi ho gayi…

15–30 sec: Balam pichkari jo tune mujhe maari… Toh seedhi saadhi chhori

31–46 sec: Haan jeans pehen ke jo tune maara thumka… Toh lattoo padosan
ki bhabhi ho gayi…

47–end: Balam pichkari jo tune mujhe maari… Toh seedhi saadhi chhori
sharaabi ho gayi… Haan jeans pehen ke jo tune maara thumka… Toh lattoo

Glass effect CSS: background: rgba(255,255,255,0.1) backdrop‑filter:
blur(10px)
